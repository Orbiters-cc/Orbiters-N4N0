# ALCOM project templates

The `avatars-2022.3.22f1` and `worlds-2022.3.22f1` template assets are copied, without modification, from
[vrc-get / ALCOM v1.9.3](https://github.com/vrc-get/vrc-get/tree/v1.9.3/vrc-get-gui/project-templates), commit
`24c4d86a4ae5a3f64c3418bccb71ed67c960f813`. They are MIT-licensed; the upstream license is in `LICENSE` beside this
notice. The application derives its Base SDK template from the avatar settings with a Base-only VPM dependency,
sets the chosen project name and generates a fresh product GUID when creating a project.
